## 🚀 Featured Project

### Boda Link

**Boda Link** is a web application designed to connect motorcycle owners with riders looking to lease motorcycles.

I built the project after noticing that motorcycle lease agreements in my community were often handled informally through word of mouth, which could lead to misunderstandings and disputes.

Boda Link provides a more structured way to manage motorcycle listings and lease agreements digitally.

🔗 **Live Demo:** https://boda-link.vercel.app/
